> 入职时公司几乎没有数字化能力，运营/财务/业务数据全部依赖纸质单据与微信流转。在资源有限、需求频繁变化的小团队环境下，主导搭建公司数字化平台技术底座。

- **架构与选型**：主导后端结构与前端技术方案，搭建基于 FastAPI + React/Vue 的全栈模板，统一 H5、钉钉小程序到 Electron 桌面应用的跨端技术栈。
- **全栈开发**：负责公共组件与业务逻辑封装，后端从业务编码深入到数据表设计、模块化架构重构；CRM、运营报表、财务 OA、数据看板等模块均深度参与并推动落地。
- **数据平台建设**：整合钉钉审批流、ERP 残留数据、纸质/零散文档等多源异构数据，搭建统一数据仓库，实现运营数据实时可视。
- **AI 工作流落地**：率先引入 Claude Code，搭建 CC Switch 代理 + OMC + Skills 等 MCP/Skills 工具链，将需求→编码→测试周期从天级显著压缩；完成 LLM API 集成，并提出专用 Agent 后端方案统一管理 AI 模块。
- **对外对接**：对接院方 HIS 系统，推进眼科检查数据归档与院内数据看板建设。

**结果**：公司从零数字化基础到拥有覆盖核心业务的数字化平台并持续线上运行。
